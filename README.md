# 여주목마 홈페이지

정적 랜딩·카테고리 사이트입니다.

## 구조

| 페이지 | 역할 |
|--------|------|
| `index.html` | **인트로** — 목마 전경 + 버튼 4개 (정보 / 입점브랜드 / 수영장 / 어울림홀) |
| `about.html` | 여주목마 정보 |
| `brands.html` | 입점 브랜드 |
| `pool.html` | 수영장·글라스룸·방갈로 예약 문의 |
| `directions.html` | **오시는 길** — 탭: 지도 / 주차·교통 / 애견운동장(무료) |

애견운동장은 기본을 **오시는 길 탭**에 두고, 입점브랜드 하단에도 짧은 소구 배너를 넣었습니다. 패널 회의 후 위치만 옮기기 쉽게 분리해 두었습니다.

## 실행

프로젝트 폴더에서:

```bash
npx --yes serve .
```

또는 `index.html`을 브라우저로 열기.
